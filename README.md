# 咸阳华星官网

深圳市咸阳华星机电有限公司的静态品牌官网，使用原生 HTML、CSS 与 JavaScript 构建，可直接部署到 GitHub Pages。当前版本采用外贸优先的双语站结构，以暖纸色、石墨黑和信号橙为主色，并将工厂影像、产品结构与技术参数作为主要视觉语言。

## 语言结构

- `/`：英文首页，面向海外采购与工程客户
- `/zh.html`：中文完整官网入口
- `/?lang=es-mx`：西班牙语（墨西哥）
- `/?lang=vi`：越南语
- `/?lang=pt-br`：葡萄牙语（巴西）
- `/?lang=es-ar`：西班牙语（阿根廷）
- `/?lang=fr`：法语

英文首页内置产品筛选、工艺能力、认证、应用场景和 RFQ 询价表单。其他外语页面通过前端语言包即时切换；中文入口保留完整的多页官网。

## 页面

- `index.html`：英文外贸品牌首页、产品、制造、品质、应用与 RFQ
- `zh.html`：中文品牌首页
- `products.html`：可搜索、按类别筛选的产品目录与详情弹窗
- `quality.html`：制造流程、认证信息与 RXM 系列关键参数
- `about.html`：公司介绍、发展历程、理念与生产现场
- `contact.html`：联系人、地址、地图入口与静态询价表单

## 设计与内容依据

- 页面信息架构参考立创商城清晰的分类导航、产品筛选与采购信息呈现方式。
- 公司简介、产品分类、联系方式、发展历程及认证概览来自咸阳华星原官网公开资料。
- 产品图片来自咸阳华星原官网公开资料。
- RXM 系列参数参考公开产品规格书。

## 本地预览

在项目根目录运行任意静态文件服务器，例如：

```bash
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173/`。

## 部署

仓库推送到 GitHub 后，在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`。

预计站点地址：

```text
https://hhcnmtkrt8-lab.github.io/huaxing-resistor/
```

## 上线前需要确认

- 认证适用范围与当前有效性应以正式证书为准。
- 产品阻值、功率、尺寸、包装与交付条件应以双方确认的规格书为准。
- 询价表单为静态 `mailto:` 方案，不会在第三方服务器保存表单内容。如需后台收集询价，可接入 Formspree、企业邮箱 API 或其他表单服务。
- 生产经营地址采用 2025 年公开产品规格书信息；正式发布前建议由公司再次确认到访接待地址。
